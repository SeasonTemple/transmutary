#14
check_origin fails closed (returns False) when neither Origin nor Referer is present
P3
📁 dashboard/csrf.py:54-61 · 👥 ce-security-reviewer · 🎯 置信 80 · 🔧 BusinessLogic → dashboard/csrf.py
影响 / Why

check_origin returns False when both Origin and Referer are absent. This means legitimate programmatic POST requests (e.g., from scripts or tools that don't send these headers) to the promote/demote endpoints would be rejected with 403 even with a valid CSRF token. This is correct security behavior (fail closed) but could cause operational issues if legitimate automation needs to hit these endpoints.

建议修复

When neither Origin nor Referer is present, the behavior depends on the threat model. For browser requests, at least one of these headers is always present. For programmatic clients (curl, etc.), neither may be present. Consider logging or metrics for header-absent requests to detect potential CSRF attempts, but do not change the deny behavior without adding alternative authentication for programmatic access.

#19
dump_all_text returns all DB text values including redacted strings
P3
📁 store/state.py:429-447 · 👥 ce-security-reviewer · 🎯 置信 75 · 🔧 InformationExposure → store/state.py
影响 / Why

dump_all_text is used in tests to audit that no credentials land in the DB. It returns all string values including those already replaced with [REDACTED]. An attacker who gains read access to test output could use the [REDACTED] markers to infer the length and character classes of the original secrets. While this is test-only code, test outputs are often retained in CI artifacts.

建议修复

Replace _REDACTION constant with a non-reversible transform (e.g., hash or random string) before storing in dump_all_text output. Or add a parameter to dump_all_text that replaces redacted values with [REDACTED] markers that cannot be distinguished from each other.

✅ `llm._neutralize_fences` 大小写不敏感替换（P1）
用 `re.escape + re.IGNORECASE` 编译正则，replace 时保留原大小写。**不要**整段 `.lower()` data block — 会破坏 URL、路径、代码块。

✅ `_ts_to_float` 失败返 `float | None`，别返 0.0（P1）
当前会把无效时间戳当 epoch 起点静默聚类。返 `None`，调用方显式处理缺失。
