#18
🗑️ Stale — audited out: Settings.__repr__ includes llm_base_url
stale
📁 config.py:188 · 🔍 tools/audit_stale_claims.py
Why stale

✅ Audited out (Stale) — endpoint identity is not a secret. LiteLLM uses it as the OpenAI-compatible base URL for whichever provider the deployment points at (KTD9). The Settings dataclass explicitly declares credentials: Credentials | None = field(default=None, repr=False, compare=False) — every real secret is excluded from repr by design. Credentials holds each value in a _Secret container whose __repr__ / __str__ refuse to print. llm_base_url is in repr on purpose: when a deployment misroutes, seeing the endpoint in a traceback is the fastest signal that the wrong provider is configured. Auditor: tools/audit_stale_claims.py::finding-18 asserts both invariants.

Strengths to Preserve

Cross-validated patterns the reviewers explicitly confirmed as correct. These are part of the project's security baseline.

Security Architecture

  • SSRF allowlist with no-redirects in all collectors (follow_redirects=False enforced end-to-end)
  • LLM prompt-injection isolation via <<>> fence in llm.py
  • R7 cross-validation: LLM security verdicts re-checked against deterministic OSV/GHSA hits
  • Credentials held in _Secret container, redacted from repr/str
  • Dashboard data layer uses explicit to_dict() allowlists, never dataclasses.asdict()
  • Report metadata written to trusted JSON sidecar, not parsed from markdown body
  • CSRF double-submit cookie + Origin/Referer host check (fail-closed by design)
  • CSP nonce middleware with fail-closed behavior on missing nonce
  • Litellm telemetry and remote cost-map fetches disabled by default (no-egress determinism)

Engineering Quality

  • Two-pipeline, one-delivery-layer architecture (KTD1) cleanly enforces mode separation
  • L1→L2→L3 funnel with L2 embedding-cosine zero-miss semantic grouping (R17/R18)
  • Deterministic API layer + LLM only for semantics (KTD2)
  • 428 tests passing — all tests use real (mocked) pipeline, no e2e gaps
  • Conventional Commits + python-semantic-release pipeline, all scopes in use
  • Clean dataclass-free credentials class, secrets cannot leak via asdict
  • SQLite WAL mode + parameterized SQL (no f-string SQL)
  • Path-traversal defense layered: sanitize_repo + realpath containment + 0700 perms
  • Artifact store sidecar JSON for trusted metadata, separate from markdown body
  • Dashboard /llms.txt + content negotiation for agent-native access
