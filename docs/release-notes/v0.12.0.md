## English

### Highlights

| Area | Change | Why it matters |
|---|---|---|
| **Dashboard** | Added an authenticated admin config control plane for tracked repos, dependency edges, trend topics, keywords, recipients, and digest hour. | The dashboard now supports day-to-day non-secret configuration instead of being read-only; provider secrets remain env-only and are never accepted by the UI or stored in SQLite. |
| **Documentation** | Refreshed the README dashboard image and capability text. | The project front page now reflects the current Web UI instead of the older demo-oriented view. |

### Compatibility

| Surface | Before | After | Action |
|---|---|---|---|
| Dashboard config | Runtime config mainly came from YAML and CLI promotion. | Authenticated settings can write non-secret overrides; effective config is YAML base + SQLite admin overrides + promoted repos. | Keep GitHub/SMTP/RSS/LLM credentials in environment variables; do not pass secrets through the UI. |
| Python package | `0.11.x` | `0.12.0` | Upgrade normally. |

### Verification

- `ruff check src tests`
- `python -m pytest -q`
- GitHub Actions release workflow built and uploaded the wheel and sdist.

### Notes

- The Web UI configures non-secret surfaces only; SMTP account/password,
  GitHub token, RSS token, and LLM API key remain environment-only.
